# 无联网相册 · Local Album Viewer

一款完全离线运行的本地照片视频管理工具，数据 100% 留在自己手里。

## 为什么有这个项目

为人父母，手机里不知不觉攒下了上百 G 的孩子成长照片和视频，散落在家人的各个手机里，整理和备份成了实实在在的痛点：

| 方案 | 问题 |
|------|------|
| 手机本地存储 | 分散在多部手机中，换手机时迁移麻烦，时间一长容易丢失 |
| QQ 空间 / 朋友圈 | 上传后画质被压缩，原图丢失；界面夹杂广告和无关内容；私密性难以保障 |
| 各类网盘 | 查找、整理、筛选极其不便；下载恢复原图麻烦；受限于平台政策和续费 |

**无联网相册** 就是为解决这些问题而做的 —— 把所有照片视频集中存在自己的硬盘 / U 盘里，通过浏览器本地服务高效浏览和管理，原图和 EXIF 元数据完整保留，绝不经过任何第三方服务器。

## 功能特性

### 📸 核心能力
- **完全离线运行**：数据全部本地存储，零网络依赖，零隐私泄露风险
- **原图无损保存**：支持 JPG、PNG、GIF、WebP、BMP、HEIC 等图片格式，完整保留 EXIF 元数据
- **视频原生支持**：支持 MP4、MOV等视频格式，自动生成缩略图，在线流畅播放
- **智能时间分组**：自动读取 EXIF 拍摄日期，按年份自动归档展示

### 🗂️ 管理功能
- **多相册管理**：自定义创建、重命名、删除相册
- **多维筛选**：按相册 / 年份 / 类型（图片/视频）/ 评分 / 标签 任意组合筛选
- **灵活排序**：按拍摄时间或更新时间升降序排列
- **批量操作**：批量选择照片后一键删除、打标签、清除标签

### 🏷️ 标注与回忆
- **标签系统**：为照片打上彩色分类标签，快速归类检索
- **评论备注**：单张照片添加多条文字记录，记录当时的故事和心情
- **评分标记**：星级（爱心）评分，快速区分珍藏级和普通照片
- **不喜欢折叠**：标记为"不喜欢"的照片自动折叠到分组底部，眼不见心不烦

### 🔐 安全与授权
- **编辑密码保护**：修改类操作（上传、删除、修改）均需输入密码确认
- **授权码机制**：授权体系，支持续费叠加
- **版本检查**：启动时自动检测新版本，支持一键查看更新日志

### ⚡ 性能优化
- **缩略图预生成**：首次扫描后自动生成缩略图，万张照片流畅浏览
- **懒加载渲染**：滚动视口按需加载，内存占用稳定
- **Range 视频流**：视频支持断点续传和拖动进度条

## 快速开始

### 双击启动

| 平台 | 启动文件 |
|------|----------|
| macOS | `双击启动_mac.command` |
| Windows | `双击启动_windows.vbs` |

启动后浏览器会自动打开相册页面（默认地址 `http://localhost:8089`）。


## 目录结构

```
根目录/
├── .bin/                  # 程序主目录（默认隐藏）
│   ├── src/               #   后端源码（Python）
│   │   ├── db/            #     数据库层（SQLite 存储）
│   │   ├── services/      #     业务逻辑层
│   │   ├── routers/       #     HTTP 路由层
│   │   └── utils/         #     工具函数集
│   ├── web/               #   前端资源（HTML/CSS/JS）
│   │   └── modules/       #     Vue 模块化业务代码
│   └── python/            #   Windows 内置 Python 运行时
├── data/                  # 照片 / 视频源文件目录（按相册分子目录）
├── .user_data/            # 用户私有数据（默认隐藏）
│   ├── previews/          #   缩略图缓存
│   └── db/                #   SQLite 数据库文件
├── 双击启动_mac.command   # macOS 一键启动
└── 双击启动_windows.vbs   # Windows 一键启动
```

## 常见问题

**Q: 照片放在哪？**
A: 首次启动后，将照片文件夹放入 `data/` 目录（每个子目录就是一个相册），然后访问首页即可自动扫描。

**Q: 数据会上传到云端吗？**
A: 绝对不会。所有图片、缩略图、数据库均在本机磁盘，程序也不主动发起任何除版本检查外的网络请求。

**Q: 默认编辑密码是多少？**
A: `111222`，可在 `.bin/src/config.py` 中修改 `PASSWORD` 字段，修改后重启生效。

**Q: 支持在多台设备间同步吗？**
A: 程序本身不做跨设备同步。建议将整个项目目录放在 U 盘 / 移动硬盘上，随身携带即插即用；或使用任意云盘单向备份根目录。
